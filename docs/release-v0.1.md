# 台灣人生 CP 值指南 v0.1

## 這是什麼

《台灣人生 CP 值指南》是一份依台灣法規、制度與官方資料整理的生活建議。每條建議都寫明三件事：要花多少錢、時間和力氣；做了能換回什麼；證據有多硬。每條也都寫出「不適用或要注意的人」，並附上可以點開查證的來源與查證日期。

- 線上使用：https://cpguide.tw/
- 離線使用：下載本版的 `index.html`，雙擊就能用，不需安裝、不需網路。

本專案改編自 eternity4719 的《高性价比人生指南》（HowToLiveBetter，CC BY 4.0），內容全部依台灣的法規與制度重寫。本專案不是原作者的官方版本，也未經原作者審核，詳見 [NOTICE.md](../NOTICE.md)。

## 資料來源原則

- 只引用台灣政府官方網站（例如衛福部、國健署、健保署、勞動部、勞保局、財政部、內政部、165 反詐騙）、全國法規資料庫，以及同儕審查期刊論文。不引用部落格、新聞或內容農場。
- 引用法規時，附上全國法規資料庫的網址與法規全名。
- 金額、比例、年齡門檻、期限都寫明適用年度，每筆來源都附查證日期。
- 找不到可靠來源的建議就刪除，不用推測填補；不確定的地方會明講。
- 證據分三級：A 是法律條文、官方公告的制度，或大型隨機對照試驗、系統性回顧；B 是觀察性研究、官方統計資料，以及官方整理的案例與手法說明；C 是專家建議、證據有限或有爭議的內容，並會說明爭議在哪。
- 每章都經過「寫稿 → 獨立查核 → 修正 → 複查」。`draft`（待查核）表示還沒經過獨立查核；`reviewed`（已查核）表示已由寫稿者以外的人對照來源查核並複查過。

## 免責聲明

本指南僅供參考，不構成醫療、法律或財務建議。健康問題請先問醫師；法律與財務的個案請諮詢專業人士。法規與金額會變動，已查核的條目也只代表查證日期當時的內容，請以來源連結的最新內容為準。

## 發現錯誤？歡迎回報

如果你發現內容有誤、來源失效，或想建議新條目，請到 GitHub Issues 開一個 issue：

https://github.com/ckolpeter/HowToLiveBetter-TW/issues/new/choose

- **內容有誤回報**：寫清楚是哪一條（例如 `labor-001`）、哪裡錯，並附上正確內容的來源連結。
- **建議新增條目**：寫清楚建議內容、適用的章節，以及至少一個可以查證的來源。

想直接修改內容的話，請先看 [CONTRIBUTING.md](../CONTRIBUTING.md)。
